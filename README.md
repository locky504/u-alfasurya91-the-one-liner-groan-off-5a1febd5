One original one-line dad joke for make.fun's "The One-Liner Groan-Off" bounty: a pun/twist a dad delivers at the dinner table, at most 140 characters. A judge model reads the jokes two at a time and picks the funniest groan.

> I changed the Wi-Fi password to 'DadIsAlwaysRight' — now the kids have to admit I'm right just to get online.

(109 characters.)

## Run it

```sh
node main.ts
```

`main.ts` prints the line to stdout and writes the identical text to `/output/entry.txt`. It validates the entry first — 1 to 140 characters, a single line, not only whitespace — and reads the file back to confirm it matches byte for byte. No network, no randomness, no input files. Requires Node 22+.
